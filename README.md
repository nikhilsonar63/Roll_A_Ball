# Roll A Ball

A 3D Unity game project developed using Unity and C#.

## About the Game

Roll A Ball is a simple 3D ball-based game where the player controls a rolling ball, collects coins, and progresses through levels.

## Features

* 3D player movement
* Rigidbody-based physics
* Jump mechanic
* Coin collection system
* Coin counter UI
* Speed-effect system
* Level system
* Scene management
* PlayerPrefs for saving coin data

## Technologies

* Unity
* C#
* Unity Rigidbody Physics
* TextMeshPro

## My Role

Designed and programmed the gameplay systems, player controller, physics-based movement, coin collection, UI interaction, and game logic.
